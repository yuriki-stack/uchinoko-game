# うちの猫ゲーム ～ステージ1：うちのおうち～ Version 1.2

Version 1.2ではゲームを「落下アイテム集め」から横スクロール型のステージゲームへ進化させました。

## 遊び方
- ゴールの🚪まで猫を移動させる
- 🐟 +10 / 🍖 +30 / ⭐ +100
- 🧹に当たるとライフ-1
- 3ライフを失うとゲームオーバー
- 🚪に到達するとステージクリア

## 操作
- PC: ← → 移動 / ↑ または Space ジャンプ / P 一時停止
- スマホ: 画面下の左右ボタン / 🐾 ジャンプ

## GitHub Pages
リポジトリの公開元に `index.html` がある状態でGitHub Pagesを有効にしてください。
