# うちの猫ゲーム Version 1.6.1

## 今回の改善
- 障害物を低く・短く調整し、通常ジャンプで越えやすく変更
- アイテムをジャンプで届く高さへ配置
- EXP表示を追加
- EXPが50ptたまるとレベルアップすることを画面上で確認可能
- ダメージ直後の連続ヒットを防ぐ無敵時間を追加

## レベルアップの仕組み
魚・おやつ・星を取るとEXPが増えます。
- 魚：10EXP（ステージ2は15EXP）
- おやつ：30EXP（ステージ2は40EXP）
- 星：100EXP（ステージ2は120EXP）
- ミッション達成報酬でもEXPが増加
- EXPが50以上になるとレベルアップ
- レベルアップすると移動・ジャンプ・ダッシュ能力が上昇

## 操作
PC：← → 移動 / Space ジャンプ / Shift ダッシュ / P 一時停止 / C 図鑑
スマホ：画面下のボタン
