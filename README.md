# うちの猫ゲーム Version 2.0

Version 1.7を土台に、2.0として遊べる統合版です。

## 主な内容
- ステージ選択：ステージ1「うちのおうち」、ステージ2「夜の庭」
- 二段ジャンプ
- ダッシュ
- EXPとレベルアップ
- 魚・おやつ・星のコレクション
- ミッションとコンボ
- 敵・ボス戦
- スコア・ベストスコア保存
- ダメージ時の無敵時間とバリア
- PC／スマホ操作対応
- 一時停止・図鑑表示

## 操作
- PC：左右キーで移動、Spaceでジャンプ、Shiftでダッシュ、Pで一時停止、Cで図鑑
- スマホ：画面下のボタン

## GitHub Pages
index.htmlをリポジトリ直下に置き、GitHub Pagesを有効にしてください。
