# うちの猫ゲーム Version 3.5

猫の能力・スキルシステムを追加したバージョンです。

## スキル
- Eキー、または「E：にゃんこスキル」ボタンで発動
- ゲージが100%になると使用可能
- 発動中は一定時間無敵・バリア状態
- スキル発動時に光のエフェクトとボーナススコアが発生

## 操作
←→ 移動 / Space ジャンプ / Shift ダッシュ / E スキル / P 一時停止


## 修正版の変更
ステージ4の横長マップにカメラ追従を追加。猫の移動に合わせて画面が横へスクロールし、右側のエリアも確認・プレイできます。


## Version 4.2
ステージ5「夜のリビング」を追加。暗闇・ライト・制限時間ギミック、横スクロールカメラ改善、PC・スマホ操作対応。


## Version 4.2
- ステージを直接選択した際の初期化を修正
- ステージ5の選択ボタンを常時有効化
- カメラの追従位置と右端表示を改善
- ステージごとの状態を開始時にリセット
- 夜のリビングのライト時間・制限時間表示を継続
