# うちの猫ゲーム ～まったり大冒険～

アップロードされた猫写真をモデルにした2Dゲーム版です。

## 起動方法
1. このフォルダ内の `index.html` をブラウザで開く
2. 「ゲームスタート」を押す

## 操作
- PC: ← / → キー
- スマホ: 画面下の左右ボタン
- Pキー または Ⅱボタン: 一時停止
- 🔊: サウンドON/OFF

## ゲームルール
- 制限時間: 60秒
- 初期ライフ: 3
- 🐟 魚: +10
- 🍖 おやつ: +30
- ⭐ レアアイテム: +100
- ❤️ ハート: ライフ回復
- 🧹 障害物: -1ライフ
- ハイスコアはブラウザに保存

## ファイル構成
- index.html
- style.css
- script.js
- images/cat.png
- images/cat_original.jpg

※ BGMは外部ファイルを使わず、ブラウザのWeb Audio APIによる簡易効果音を実装しています。
