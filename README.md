# うちの猫ゲーム Version 1.7

## 今回の追加・改善
- 二段ジャンプを実装
- 画面にジャンプ回数を表示（0/2、1/2、2/2）
- Spaceキーまたはスマホのジャンプボタンで二段目も発動
- 二段ジャンプ時に「二段ジャンプ！」を表示
- ダメージ後の短い無敵時間を追加
- バリア能力が発動した場合、1回だけダメージを無効化
- ステージ1・2、敵、ボス、ミッション、コンボ、レベルアップを継承

## レベルアップ
EXPが50ptたまるとレベルアップします。
魚・おやつ・星・ミッション達成でEXPを獲得し、移動速度・ジャンプ力・ダッシュ性能が上昇します。

## 操作
PC：← → 移動 / Space ジャンプ（二段ジャンプ可） / Shift ダッシュ / P 一時停止 / C 図鑑
スマホ：画面下の移動・ジャンプ・ダッシュ・図鑑ボタン
